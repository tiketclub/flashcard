ENGLISH FLASHCARD 1000
Versi pertama aplikasi flashcard untuk Android.

Fitur:
- Indonesia -> English dengan ketuk kartu
- 1.000 kartu
- kategori
- acak
- progress tersimpan di perangkat
- tombol benar/belum hafal
- text-to-speech English
- offline setelah aplikasi web terpasang/cached

Catatan:
Versi ini dibuat sebagai PWA yang dapat dipasang ke layar utama Android melalui Chrome.
Untuk instalasi PWA, buka aplikasi dari alamat web HTTPS, lalu pilih menu Chrome > Add to Home screen / Install app.

Versi APK native belum dapat dikompilasi di lingkungan kerja ini karena Android SDK/build tools tidak tersedia.
